# Aerostep — web prototype

Walk to fly. A prototype of an iOS wellness tracker that turns daily steps into flight miles.

- Open `index.html` (or the GitHub Pages link). Steps are simulated with the buttons on the Today tab.
- Design prototype only; the production app is planned in SwiftUI.
